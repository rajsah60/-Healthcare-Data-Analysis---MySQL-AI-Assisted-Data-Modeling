# Healthcare-Data-Analysis - MySQL + AI-Assisted-Data-Modeling

## 📌 Project Overview
- This project is a healthcare data analysis project built using MySQL.

- The main objective of this project is to use SQL to answer practical healthcare - related business questions and
  analyze patient activity, doctor appointments, treatments, hospital billing, payments & revenue.
   
- AI assistance was used during the data modeling phase to understand and validate the relationships between tables.


## 🎯 Project Objectives

 The main objectives of this project are:

- Analyze patient registration data
- Analyze doctor experience and appointment volume
- Understand appointment and treatment patterns
- Analyze treatment costs
- Calculate doctor-wise revenue
- Analyze hospital branch billing
- Examine payment status
- Identify failed payments by insurance provider
- Rank doctors based on generated revenue
- Use SQL to answer healthcare business questions


## 🗄️ Database Tables

 1. Doctors
 2. Patients
 3. Appointments
 4. Treatments
 5. Billing
